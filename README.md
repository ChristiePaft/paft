# Chat Feature Testing Checklist

## Basic Functionality
- [ ] Send and receive messages
- [ ] Edit and delete messages
- [ ] Verify delivery and read receipts
- [ ] Check file and image attachments

## Edge Cases
- [ ] Send message while offline
- [ ] Send long messages (over 1000 characters)
- [ ] Copy-paste from different apps
- [ ] Mention users who are inactive or blocked

## UI/UX
- [ ] Verify emojis render properly
- [ ] Check light/dark mode display
- [ ] Verify accessibility with keyboard navigation
